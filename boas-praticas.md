# Boas Práticas de Uso do Git e GitHub

1. **Mensagens de commit descritivas:** Escreva mensagens claras que expliquem o porquê da alteração.
2. **Uso de Branches para novas features:** Nunca trabalhe diretamente na branch principal; crie branches específicas.
3. **Revisão por Pull Requests:** Sempre utilize Pull Requests e solicite revisões antes de integrar código na main.
